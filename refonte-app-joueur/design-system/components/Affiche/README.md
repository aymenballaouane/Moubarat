# Affiche

Le haut de l’accueil : le match vedette du soir en photo plein écran, avec le seul bouton rouge de l’écran.

- Photo de terrain de nuit, voile du haut `night-veil` vers le bas `ink` plein, pour que le texte du bas reste lisible.
- De haut en bas : micro-label Mono « L’AFFICHE DE CE SOIR » avec le point rouge, le nom du match en Bebas (≈ 76 px, une ou deux lignes), une ligne en Barlow (heure en gras · lieu · format · niveau), les initiales des inscrits avec « Plus que 3 places · 500 DA », puis REJOINDRE LE MATCH en `mb-btn mb-btn--block`.
- Si des potes sont inscrits : une ligne « **Yanis et Riad** y sont déjà » au-dessus du bouton.
- Des points sous le bouton : l’affiche défile vers les autres matchs du soir (le point actif est un trait blanc).
- Choix du match vedette (à coder) : le match de ce soir le plus proche du joueur qui a encore des places.
