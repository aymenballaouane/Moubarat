# ActionTile

Les deux grands rectangles de l’accueil, RÉSERVER (un terrain) et CRÉER (un match) — élément intouchable du langage Moubarat.

- Toujours une photo plein cadre : RÉSERVER = un terrain (le lieu), CRÉER = des joueurs (la communauté). Jamais une icône sur dégradé.
- Titre Bebas 34 px avec `line-height` 1.0 et un peu d’espace au-dessus, pour que l’accent du É ne soit jamais rogné.
- Même structure interne sur les deux, bouton flèche rouge à la même position absolue.
- Toute la surface est cliquable.
