# PoteCard

La carte « Tes potes jouent bientôt » de l’accueil : un pote, le match où il est inscrit, un bouton pour le rejoindre.

- Haut : initiale du pote en Bebas dans un rond `ink-3`, prénom en gras, « 7 matchs avec toi » en `text-2`.
- Milieu : vignette photo du terrain (voile padel si c’est du padel), heure Bebas, nom du match, « lieu · places restantes ».
- Bas : JE LE REJOINS en bouton blanc plein (le rouge reste à l’affiche).
- Cartes de 250 px qui défilent sur le côté, gouttière `s-4`. Toute la carte ouvre le détail du match.
- Les potes sont les joueurs avec qui le joueur a le plus joué ; la section disparaît si aucun n’est inscrit nulle part.
